# Network Scanning

Defensive network scanning inventories hosts, services, and exposed ports so teams can compare the observed attack surface with the approved asset inventory. Scans should be authorized, rate-limited, and scheduled to avoid disrupting production systems.

Unexpected internet-facing services should be verified with the system owner, restricted with firewall rules, and assessed for software version and known vulnerabilities. A scan result is an observation, not proof that a service is exploitable.
